## Principal results

- **Force comparison**: pattern cosine 0.933, Pearson *r* 0.865, effort ratio
  **1.71×**, discrepancy localised to the elbow antagonists (triceps lateral and
  medial driven at 3–4.5× the prescribed force).
- **Target entropy**: default −9 → tuned −19 halves reaching error;
  closest approach 0.132 → 0.074 m.
- **Tuning vs algorithm**: 38 % vs ~6 %.
- **Across all 15 policies**: effort ratio 1.21–2.30×; economy ranks inversely
  to accuracy.
- **Latency**: 2165 µs classical vs 295 µs network (7.3×); 393,750 parameters.

## Stated limitations (Ch. Conclusion, §Critical assessment)

Single seed for the principal result; three seeds for the comparison; no
significance testing anywhere; success rate 0–4 % under a criterion a privileged
controller meets ~7 % of the time; three of four algorithms untuned; entirely
computational, no EMG or human data; rotator cuff absent so shoulder rotation is
constrained.

## Withdrawn from the previous version

Four-algorithm results table, Wilcoxon p-values (0.002 / 0.014 / 0.004),
convergence-rate claims, synergy and co-contraction analyses, domain-randomisation
breakdown, reward-sensitivity study. Basis for withdrawal is documented in the
conclusion.

Surviving unchanged: latency, parameter count and footprint, Hill-solver
validation vs MuJoCo (5.25 % NRMSE), muscle-function validation (7/7), model
stability.
