\cellcolor{navy} & \textbf{How to read this document.} It is written to be
answerable at every level. Ordinary text carries the technical account. Boxes
marked \textbf{\color{accent}IN PLAIN LANGUAGE} restate the same idea with no
assumed background --- if a section is opaque, read its box first and then the
text. Boxes marked \textbf{\color{greenrule}WHY IT IS THIS WAY} explain a design
decision rather than describing it. Boxes marked \textbf{\color{warmrule}WHAT
GOES WRONG} record a failure that actually occurred in this project and how it
presented.

Nothing here is aspirational. Every number is measured, every parameter value is
the one in the code, and every failure described actually happened.
